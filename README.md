# Restaurant Table Reservation System 🍽️

A Java-based web application for managing restaurant table reservations, restaurant information, and customer interactions.

## Technologies Used
- Java
- Java Servlets
- JSP
- Maven
- HTML and CSS

## Features
- User registration and login
- Restaurant and table management
- Table reservation management
- Customer and restaurant owner dashboards
- Restaurant reviews
- Administrative dashboard

## Project Structure
- `model/` — Application data models
- `service/` — Business logic
- `servlet/` — Request handling
- `webapp/` — JSP pages and web resources
- `data/` — File-based application data

## Project Purpose
Developed as an Object-Oriented Programming project to apply Java OOP concepts and web application development techniques.
